# Trends

Лента трендов коротких видео для TikTok, Instagram Reels и YouTube Shorts.

## Структура

- `site/` — готовые статические файлы сайта; точка входа — `site/index.html`.

## Публикация в Cloudflare Pages

Подключите репозиторий и укажите:

- Production branch: `main`
- Build command: оставить пустой (сборка не требуется)
- Build output directory: `site`
- Root directory: `/` (корень репозитория)

Изменения в `main` будут публиковаться автоматически после подключения. Для локального просмотра запустите `python3 -m http.server 8000 --directory site` и откройте `http://localhost:8000`.

Данные ленты публикуются статическим снимком.

## Аналитика

События принимаются на `POST /api/analytics`. Дашборд доступен по `/analytics` после настройки доступа.

1. Создайте базу D1 и примените к ней по порядку `migrations/0001_analytics.sql` и `migrations/0002_device_and_player_open.sql`. Для каждого файла используйте `npx wrangler d1 execute ИМЯ_БАЗЫ --remote --file=ПУТЬ_К_ФАЙЛУ`. Если первая миграция уже применена, выполните только вторую перед деплоем.
2. В настройках проекта Cloudflare Pages подключите базу D1 с именем привязки `ANALYTICS_DB`. Для preview можно использовать отдельную базу.
3. В настройках Pages добавьте секрет `ANALYTICS_PASSWORD` с длинным случайным паролем. Вход в дашборд с логином `analytics`. Если секрет отсутствует, дашборд закрыт.
4. Перезапустите деплой. После визита в ленту проверьте, что `POST /api/analytics` отвечает `204`, а новая сессия появилась в дашборде.

Для локальной проверки примените обе миграции по порядку командой `npx wrangler d1 execute ANALYTICS_DB --config wrangler.local.jsonc --local --file=ПУТЬ_К_ФАЙЛУ`, задайте `ANALYTICS_PASSWORD` в локальном `.dev.vars` и запустите `npx wrangler pages dev site --d1 ANALYTICS_DB=00000000-0000-4000-8000-000000000001` из корня репозитория. Файл `.dev.vars` храните локально.

Для TikTok, YouTube и Instagram считаются открытия плеера на три секунды подряд в видимой вкладке. Одно открытие на ролик за сессию. Отдельно учитываются переходы на оригинал. Старые измерения воспроизведения хранятся в базе по прежнему типу события.

В отчётах есть фильтр «Мобильные / Десктопы». Планшеты относятся к мобильным, а для старых записей предусмотрена категория «Не определено». Уникальность посетителя определяется по браузеру.
